# Vyapari Mitra — Paytm Build for India AI Hackathon (Mumbai Edition)

**Track:** Merchant Growth AI · **Team:** The Vision (Ayush Korde & Harshita Girase) · **Powered by:** Sarvam AI

A voice-first, multilingual AI business copilot for Paytm merchants — with a built-in **Fraud Shield** that
voice-verifies payment screenshots and flags silent QR-swap fraud in real time.

## What's in this repo

- **[`demo/`](demo/)** — the working prototype: a Sarvam AI–powered chat + dashboard web app, installable as a PWA.
  Supports 11 languages (Hindi, Marathi, Bengali, Gujarati, Tamil, Telugu, Kannada, Malayalam, Punjabi, Odia, English),
  voice input/output, and a Fraud Shield that cross-checks a mock Paytm settlement ledger in real time.
  Open `demo/index.html` in a browser to try it (add your own Sarvam AI API key, or use it offline with the
  built-in mock responses).

- **[`pitch/`](pitch/)** — the hackathon pitch deck: `build.js` (pptxgenjs source), the generated
  `vyapari-mitra-deck.pptx` / `.pdf`, and supporting assets (logo, screenshots).

## Why Vyapari Mitra

Everyone else builds an English-first advice chatbot. Vyapari Mitra is the only one that talks in the merchant's
own language **and** protects their money in real time — see the deck's comparative analysis and system
architecture for details.
